Problem Statement Slide 02

The Fragmented & High-Friction Placement Journey

Over 1.5 million engineering graduates in India face 4 major bottlenecks during campus recruitment:

01

Fragmented Tools

Students juggle 5-6 disconnected portals: LeetCode for DSA, Indiabix for Aptitude, Notion for job tracking, and random Google Docs for resumes.

02

No Voice Practice

Engineering students excel in coding on paper, but freeze in live interviews due to lack of realistic voice and STAR-method communication practice.

03

Blind ATS Rejections

Students apply to Google, Amazon, and TCS using identical generic resumes without knowing company-specific keywords, metrics, or red flags.

04

Unrealistic Exams

Traditional practice apps lack real exam environments like TCS iON / AMCAT countdown palettes, negative marking, and mathematical explanations.

Our Solution Slide 03

Introducing NEXORA: The All-In-One Unified Suite

A single intelligent platform engineered to guide students through every stage of recruitment.

🎙️

AI Voice Mock Interviews

Speaking avatar with natural speech synthesis + live microphone transcription. Delivers instant STAR scorecard, confidence rating, and ideal responses.

📝

TCS iON Exam Simulator

Real test portal with countdown timer, official question palette (Answered, Marked for Review), and complete step-by-step mathematical explanations.

📄

Company Resume Analyzer

Evaluates resumes specifically against Google, Amazon, TCS, and startups. Delivers ATS match score, Positives/Negatives, and Google XYZ formula rewrites.

💻

DSA Arena & Test Runner

Multi-language code workspace (JavaScript, Python, C++, Java) with sandboxed test case execution, complexity guide, and company-tagged roadmaps.

📋

Job Application Kanban

6 recruitment stages (Wishlist, Applied, OA, Interview, Offer, Rejected) with conversion funnel metrics and curated 2026/2027 off-campus drives.

🤖

24/7 Nexora AI Mentor

Full-page assistant + global floating widget for continuous placement queries, salary negotiation tips, and Gemini API integration.

Architecture & Tech Stack Slide 04

Engineered for Blazing Speed & Zero Downtime

Zero backend failure points: 100% persistent, responsive, and deployable worldwide.

Client-First High Performance Stack

  • ⚡ React 18 + Vite + TypeScript: Sub-second bundle transforms, strict type safety, zero compile runtime overhead.
  • 🎙️ Web Speech API: Native browser speech synthesis (Text-to-Speech) and recognition (Voice-to-Text) with zero API latency and zero cost.
  • 🎨 Tailwind CSS Design System: Ultra-modern dark glassmorphism, responsive grid layouts, and custom animation keyframes.
  • 🛡️ LocalStorage State Sync: All solved problems, interview scores, aptitude results, and job boards persist across browser sessions.

Hybrid AI Evaluation Engine

  • 🧠 Heuristic Placement Rules: Pre-loaded with deep domain rubrics for Google, Amazon, TCS, Goldman Sachs, and startups (works 100% offline).
  • ✨ Optional Gemini 1.5 Integration: Seamless plug-in support for free Google Gemini API keys for candidates wanting live LLM follow-ups.
  • 📊 Placement Readiness Index: Weighted formula dynamically aggregating DSA (30%), Aptitude (25%), Mock Interviews (25%), and Resume ATS (20%).
