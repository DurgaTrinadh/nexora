Architecture Slide 04

Client-Side Zero Downtime Architecture

Client Engine & Performance

  • • React 18 + Vite + TypeScript: Sub-second hot reload, strict type safety.
  • • Web Speech API: Speech synthesis and recognition without third-party API costs.
  • • LocalStorage Sync: Test scores, solved DSA, and jobs persist across sessions.
  • • Tailwind CSS: Sleek dark glassmorphic responsive UI.

Hybrid AI Intelligence

  • • Heuristic Rule Engines: Pre-loaded company profiles (works 100% offline).
  • • Readiness Index: DSA (30%), Aptitude (25%), Interviews (25%), Resume (20%).
  • • Google XYZ Formula: Concrete bullet rewrite suggestions.
  • • Optional Gemini 1.5: Plug-in free API key for live dynamic responses.
